# 动能回流自动扫描与当日信号看板设计

日期：2026-07-30  
状态：用户已确认设计内容，待书面规格最终审核

## 1. 目标

把现有“动能回流 -> 1H首次回流”手动瞬时扫描升级为全局单实例的自动扫描与当日信号看板，避免符合条件的首次回流信号因下一次扫描结果覆盖而丢失。

本次同时完成：

- 动能回流专用最低24小时成交额从300万USDT调整为200万USDT。
- 扫描范围从纯加密永续扩展到除股票类资产外的币安USDT永续品种。
- 自动扫描默认开启，服务启动后立即补扫，之后在北京时间每个整点后的第3分钟执行。
- 管理后台提供全局自动扫描开关。
- 当日信号持久留存、质量评分、状态更新和新鲜度排序。

本功能保持只读，不连接下单链路，不修改Predicta、RJ、风险、仓位、止损、止盈、追踪或盈亏统计。

## 2. 扫描宇宙

数据源仍为币安主网USDT合约，仅使用已经收盘的1小时和日线K线。

### 2.1 允许范围

- `contractType=PERPETUAL`，且`underlyingType`为`COIN`、`INDEX`或其他非股票类型。
- `contractType=TRADIFI_PERPETUAL`时，只允许：
  - `underlyingType=COMMODITY`
  - 未来可能出现的`underlyingType=FX`
- 包含加密货币、加密指数、RWA、黄金、白银、铂金、钯金、铜、原油、天然气及未来币安提供的外汇永续。

### 2.2 排除范围

- `EQUITY`
- `HK_EQUITY`
- `KR_EQUITY`
- `PREMARKET`
- 股票、ETF及拟上市公司合约
- 稳定币互相交易的合约
- 名称含`BULL`、`BEAR`、`UP`、`DOWN`的杠杆代币

股票排除优先使用币安`exchangeInfo`元数据，不仅依赖静态币种名单。未知的`TRADIFI_PERPETUAL`资产类型失败关闭，不自动纳入。

### 2.3 流动性

- 动能回流使用独立常量`REFLOW_MIN_VOLUME_USDT=2_000_000`。
- 不修改其他扫描器共享的`MIN_VOLUME`。
- 成交额使用币安24小时`quoteVolume`。
- 活跃事件对应的旧币种继续加入扫描并集，即使其当前成交额临时跌破门槛，避免已开始事件失去后续状态更新。

按2026-07-30实时核验的币安数据，上述规则当时匹配283个品种；该数量会随24小时成交额变化，不作为固定上限。

## 3. 自动调度

### 3.1 全局设置

新增`momentum_reflow_settings.json`：

```json
{
  "version": 1,
  "auto_scan_enabled": true,
  "updated_at": 0,
  "updated_by": ""
}
```

- 默认开启。
- 文件不存在时使用默认值并安全创建。
- 文件损坏或版本错误时失败关闭自动扫描，保留手动扫描能力，并在管理后台显示错误。
- 保存使用临时文件、`fsync`和原子替换。

### 3.2 执行时点

- `macd-bot`启动且开关开启时，立即补扫一次。
- 此后在北京时间每个整点后的第3分钟执行一次。
- 管理员从关闭切换为开启时，立即触发补扫，然后恢复固定时点。
- 从开启切换为关闭时，不强制中断已经开始的扫描；当前扫描安全完成后不再启动新自动任务。
- 手动“立即扫描”按钮始终保留，自动开关关闭时也可使用。

### 3.3 并发

- 资金费率、普通扫描、动能回流手动扫描和动能回流自动扫描继续共用同一个全局扫描锁和工作线程身份。
- 任意扫描正在运行时，自动扫描不排队，记录“因扫描占用跳过”。
- 手动请求在已有任务运行时返回当前扫描状态，不创建第二个工作线程。
- 所有缓存、进度和状态写入必须验证当前工作线程身份，过期线程不得覆盖新状态。
- 调度器在单个`macd-bot`进程中只启动一次；测试或重复导入不得创建第二个调度线程。

## 4. 当日信号历史

新增`momentum_reflow_daily_signals.json`，版本为1，使用北京时间日期分组保存信号。

### 4.1 唯一键

信号唯一键由以下字段组成：

```text
symbol | direction | breakout_time | return_open_time
```

自动扫描和手动扫描走同一写入函数。相同唯一键只更新，不重复新增。

### 4.2 保存字段

每条信号至少保存：

- 唯一键
- 北京时间交易日
- 品种、品种类别和方向
- 突破时间、首次回流K线开盘/收盘时间
- 首次发现时间、最后看到时间
- 价格、EMA50、收盘距离ATR
- 回流窗口`N/5`
- 最大扩张ATR
- 日线确认类型和等级
- 突破量比
- 质量分、质量标签
- 当前状态和状态原因

### 4.3 留存与状态

- 信号首次进入当日历史后，当天不因后续扫描结果变化而删除。
- 页面默认只读取北京时间当天记录。
- 历史文件不自动删除，为后续质量评分统计校准保留数据。
- 每次扫描后使用当前事件账本更新已记录信号状态：
  - `RETURN_WINDOW`：回流有效
  - `CONSUMED`且原因为`return_window_complete`：窗口结束
  - 其他终止、斜率反转或失效原因：事件失效
- 关闭自动扫描不会删除状态、账本或历史。
- 保存使用临时文件、`fsync`和原子替换。
- 单个币种、日线数据或历史文件更新失败时保留上一份有效数据，不用空结果覆盖。

## 5. 质量评分

质量评分是透明的结构评分，不宣称等于胜率或盈利概率。

### 5.1 日线确认：最高30分

- `strong_momentum`，等级3：30分
- 吞没、锤子/流星、早晨/黄昏之星，等级2：24分
- 顶底分型，等级1：18分

### 5.2 突破量比：最高25分

- 1.5倍对应15分。
- 1.5倍至3.0倍之间线性增加。
- 3.0倍及以上封顶25分。

### 5.3 最大扩张：最高20分

- 1.5 ATR对应12分。
- 1.5 ATR至3.0 ATR之间线性增加。
- 3.0 ATR及以上封顶20分。

### 5.4 回流距离：最高15分

- 收盘恰好位于EMA50对应15分。
- 绝对收盘距离从0至0.35 ATR线性递减。
- 0.35 ATR对应0分。

### 5.5 回流窗口：最高10分

- 1/5：10分
- 2/5：8分
- 3/5：6分
- 4/5：4分
- 5/5：2分

总分四舍五入为整数并限制在0至100：

- 75至100：高质量
- 60至74：标准
- 0至59：观察

## 6. 排序与新鲜度

- 当日列表第一排序键为`return_open_time`倒序，最新首次回流在最上方。
- 相同首次回流时间时，第二排序键为质量分倒序。
- 再相同时按突破量比倒序、币种名称升序，保证排序稳定。
- 新鲜度依据首次回流K线收盘时间计算并显示具体时间差，不用质量分替代时间新鲜度。

手动扫描仍更新同一个页面，但不清空当日历史。

## 8. 管理后台

- 在管理后台配置区域新增“动能回流自动扫描”开关。
- 开关显示：
  - 当前启用状态
  - 上次修改时间
  - 最近一次自动扫描时间
  - 最近错误
- 读取状态要求管理员登录。
- 修改接口要求管理员登录，并校验请求值必须为布尔值。
- 管理后台只修改独立扫描设置文件，不修改`demo_bot_config.json`、用户交易配置或API密钥。
- 普通用户页面只显示自动扫描状态，不能修改。

## 9. 故障处理

- 交易所宇宙、K线或日线请求失败：记录错误，保留上一轮页面数据。
- 设置文件损坏：自动扫描失败关闭，管理后台显示错误；手动扫描保持可用。
- 账本或当日历史不可读：不覆盖原文件，扫描返回明确错误。
- 原子保存失败：保留旧文件并报告错误。
- 扫描运行超过预期时不按时间强制解锁；只有真实工作线程结束后才释放全局扫描位。
- 服务重启后从账本和当日历史恢复，不重复创建同一信号。
- 自动扫描关闭期间不会进行后台API请求。
