# R 绩效复盘可视化设计

日期：2026-07-29  
状态：已确认，待实施

## 1. 目标

在 AXIOM Quant 现有账户净值统计区增加一套 R 绩效复盘视图，用统一风险单位衡量策略表现，回答以下问题：

- 策略累计赚取或亏损了多少 R；
- 每笔交易的数学期望是否为正；
- 平均盈利能否覆盖平均亏损；
- 盈利总量能否覆盖亏损总量；
- 策略经历了多大的 R 回撤；
- 利润在多空方向、平仓原因和 MFE 转化上如何分布。

本功能只增加统计和展示，不修改开仓、止损、止盈、仓位计算或交易执行逻辑。

## 2. 设计选择

采用“B 平衡复盘区”：

- 保留现有账户权益曲线和四项权益指标；
- 在权益曲线下方增加独立的 R 绩效区域；
- 首屏展示六项核心 R 指标和累计 R 曲线；
- 次要诊断数据放入“更多复盘”折叠区；
- 复用现有 1W、1M、3M、6M、1Y、ALL 时间范围；
- 普通交易面板与演示引擎采用相同组件和相同统计口径。

不采用仅增加单一卡片的极简方案，因为它无法同时呈现期望、回撤和盈亏结构；不采用完整研究终端方案，因为会显著增加首屏信息密度。

## 3. R 统计口径

### 3.1 基础定义

单次出场记录的实际 R：

```text
exit_r = realized_pnl / initial_risk_usdt
```

优先使用记录中已经持久化的 `r`。当 `r` 缺失但 `risk > 0` 时，使用 `pnl / risk` 兼容计算。

`risk <= 0`、风险值缺失或结果非有限数的记录不参与 R 指标计算，并计入 `excluded_records`。

### 3.2 完整交易归并

一笔仓位可能产生多次分批出场。统计时必须先归并完整交易：

- 有 `signal_key`：相同 `signal_key` 的所有出场记录归并为一笔完整交易；
- 无 `signal_key`：旧记录按独立交易处理；
- 完整交易 R：该组所有有效出场记录的 `r` 之和；
- 完整交易 MFE：该组记录中最大的有效 `mfe_r`；
- 完整交易 MAE：该组记录中最大的有效 `mae_r`；
- 完整交易最终平仓时间：该组最晚的出场时间；
- 平仓原因：保留该组全部原因，最终原因单独标识。

完整交易数、胜率、期望值、连续亏损等按归并后的完整交易计算，不能按出场记录数计算。

### 3.3 时间范围

- R 面板与权益曲线共用当前时间范围；
- 完整交易按最终平仓时间归入 1W、1M、3M、6M、1Y 或 ALL；
- 区间起点按当前时间减去对应自然天数计算；
- 当前未平仓仓位不进入已实现 R 指标；
- 持仓浮动 R 如需展示，只作为独立实时值，不能改变累计净 R、胜率、期望值和 Profit Factor。

## 4. 核心指标

首屏显示六项指标：

### 4.1 累计净 R

```text
net_r = sum(trade_r)
```

### 4.2 每笔期望

```text
expectancy_r = net_r / valid_trade_count
```

它是判断策略在当前样本中是否为正期望的核心指标。

### 4.3 平均盈亏比

```text
average_payoff_ratio = average_win_r / abs(average_loss_r)
```

该指标衡量一笔平均盈利能够覆盖多少倍的一笔平均亏损。

### 4.4 Profit Factor

```text
profit_factor = gross_profit_r / abs(gross_loss_r)
```

它衡量全部盈利 R 对全部亏损 R 的覆盖能力，与平均盈亏比不是同一指标。没有亏损样本时返回空值而不是伪造无限值。

### 4.5 平均盈利 / 平均亏损

在一张卡片中并列显示：

```text
average_win_r = sum(winning_trade_r) / winning_trade_count
average_loss_r = sum(losing_trade_r) / losing_trade_count
```

`trade_r == 0` 的保本交易不进入平均盈利或平均亏损。

### 4.6 最大回撤 R

将完整交易按最终平仓时间排序，生成累计 R 序列：

```text
cumulative_r[n] = cumulative_r[n-1] + trade_r[n]
max_drawdown_r = max(previous_peak_r - cumulative_r[n])
```

最大回撤显示为负值，例如 `−6.37R`。

## 5. 辅助信息与更多复盘

R 区域标题栏显示：

- 完整交易数；
- R 胜率；
- 最长连续亏损；
- 有效 R 样本数；
- 被排除记录数。

“更多复盘”折叠区显示：

- 多单净 R、空单净 R；
- 各平仓原因的交易数和净 R；
- 平均 MFE R；
- MFE 利润捕获效率；
- 最大单笔盈利 R；
- 最大单笔亏损 R。

MFE 利润捕获效率只对 `mfe_r > 0` 且完整交易 R 为正的交易计算：

```text
mfe_capture_efficiency = sum(realized_positive_r) / sum(mfe_r)
```

结果限制在统计解释层，不用于自动改变出场逻辑。若数据不足则显示 `--`。

## 6. 可视化结构

R 绩效区域位于现有权益曲线下方：

1. 标题栏：`R PERFORMANCE`、样本信息和当前范围；
2. 六项指标卡：桌面端一行六列或两行三列，移动端依次降为三列、两列；
3. 累计 R 曲线：零轴清晰可见，正值使用绿色，负值使用红色；
4. 更多复盘：默认折叠，展开后显示方向、原因和 MFE 诊断。

视觉延续 AXIOM 的钛金灰、深黑背景和克制发光风格。动画只使用 `transform` 和 `opacity`，不引入前端框架或依赖。

## 7. 后端结构

新增单一职责的 R 汇总逻辑，输入交易记录和可选时间起点，返回序列化结果：

```text
summarize_r_performance(trade_log, cutoff_time=None) -> {
    valid_trade_count,
    valid_exit_record_count,
    excluded_records,
    net_r,
    expectancy_r,
    win_rate,
    average_win_r,
    average_loss_r,
    average_payoff_ratio,
    profit_factor,
    max_drawdown_r,
    max_consecutive_losses,
    largest_win_r,
    largest_loss_r,
    direction_breakdown,
    exit_reason_breakdown,
    average_mfe_r,
    mfe_capture_efficiency,
    cumulative_r_points
}
```

快速状态和完整状态接口调用同一个汇总函数，前端不重复实现公式。为减少高频轮询成本，可一次返回 ALL 的完整交易序列，由前端仅负责选择已经计算好的范围，或在后端提供按范围生成的轻量结果。实施时优先选择不会重复解析大历史文件的现有缓存模式。

## 8. 前端结构

- 新增 R 面板渲染函数；
- 时间范围按钮触发权益曲线与 R 面板同步刷新；
- 普通交易视图和演示引擎视图复用相同 HTML 结构、CSS 类和渲染函数；
- 指标卡提供简短提示，明确“平均盈亏比”和“Profit Factor”的区别；
- 无数据时显示 `等待有效 R 交易记录`；
- 有排除记录时显示 `未计入 N 条无有效风险记录`；
- 所有值使用固定小数格式，避免 `NaN`、`Infinity` 或空字符串进入界面。

## 9. 兼容与异常处理

- 新记录优先使用持久化 `r`；
- 旧记录允许使用 `pnl / risk` 回算；
- `signal_key` 缺失的旧记录不尝试模糊归并，避免误合并不同仓位；
- 时间无法解析的记录不进入区间统计，并计入排除数；
- 没有盈利或没有亏损样本时，相关平均值或比例显示 `--`；
- R 统计异常不能阻断现有状态接口，失败时返回空统计和明确的数据状态。

## 10. 验证标准

单元测试至少覆盖：

1. 单次完整盈利和亏损；
2. 同一 `signal_key` 的两次分批出场正确相加；
3. 不同 `signal_key` 不被合并；
4. 无 `signal_key` 的旧记录独立计数；
5. `r` 缺失时使用 `pnl / risk`；
6. `risk <= 0`、非法时间和非有限值被排除；
7. 盈利、亏损、保本对胜率和均值的影响；
8. 平均盈亏比与 Profit Factor 公式；
9. 最大回撤 R；
10. 最长连续亏损；
11. 时间范围边界；
12. MFE 捕获效率；
13. 普通面板与演示引擎返回相同口径。

界面验证至少覆盖：

- 桌面、平板和手机断点；
- 1W、1M、ALL 切换同步；
- 无数据、仅盈利、仅亏损、含排除记录四种状态；
- 现有权益曲线、持仓卡片和最近交易数据绑定不受影响。

## 11. 成功标准

- 同一批交易在普通面板和演示引擎得到完全一致的 R 指标；
- 分批减仓不会重复增加完整交易数；
- 当前服务器样本可从 54 条出场记录正确归并为 52 笔完整交易；
- 当前样本的校验基准为：累计净 `+3.1941R`、每笔期望 `+0.0614R`、平均盈利 `+1.2834R`、平均亏损 `−0.6669R`、平均盈亏比 `1.9243`、Profit Factor `1.1842`、最大回撤 `−6.3729R`；
- 所有统计结果可由原始交易记录复算；
- 本功能不产生任何交易指令或策略行为变化。
